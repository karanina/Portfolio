# Point of Sale System for Jewellery Stores

This project is designed to **practice Test Driven Development (TDD)** while building a functional Point Of Sale (POS) system tailored to the jewellery industry.

---

## Project Overview

The software is a **POS system specific to jewellery retail**. Jewellery items often involve a combination of **different metals, gemstones, sizes, widths, and other attributes** depending on the type of item.  

Additionally, **sales are frequently negotiated**, meaning prices and discounts are not uniform. This project aims to handle the **unique challenges and idiosyncrasies of a jewellery store**, including:

- Complex product specifications  
- Manual or customer-specific discounts  
- Inventory tracking for high-value items
